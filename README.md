🎮 Jogo da Forca

Um clássico que atravessa gerações, recriado com HTML, CSS e JavaScript.

Este projeto foi desenvolvido como forma de praticar conceitos fundamentais do desenvolvimento web, transformando uma ideia simples em uma aplicação completa e interativa. O jogo permite que o usuário tente descobrir uma palavra secreta antes que o boneco da forca seja completamente desenhado.

🚀 Demonstração

🔗 Acesse o projeto:
https://aula-tecnologias-web.vercel.app

✨ Funcionalidades
🎲 Seleção aleatória de palavras
🔤 Validação de letras digitadas
🚫 Controle de letras já utilizadas
🎨 Interface personalizada com tema Dark Tech
🖌️ Desenho da forca e do boneco utilizando Canvas
🎉 Animação de confete ao vencer
⚠️ Efeito visual de derrota
🔔 Notificações amigáveis utilizando Toastify
⌨️ Suporte à tecla Enter para envio de letras
🔄 Reinício rápido da partida
📖 Página explicativa com instruções do jogo

⚙️ Como Executar o Projeto

Clone o repositório:

git clone <url-do-repositorio>

Acesse a pasta:

cd jogo-da-forca

Instale as dependências:

npm install

Execute o projeto:

npm run dev
